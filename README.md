Declaración breve de uso de IA
## Registro de uso
**Herramienta:** ChatGPT
**Modelo:** GPT-5
**Parte de la actividad en la que se uso:** introducción y apoyo encomprensión de conceptos, y ayuda en casos de prueba adicionales que no sabia como abordar
**Prompt:**
1. En mi curso de testing de la universidad me pidieron resolver una actividad para abordar conceptos de coverage y gabordar tests. Esta es mi act... ayudame a comprender conceptos clave de coverage patra comenzar a abordarla


2. Tengo este resultado de coverage en Python:

src/pricing.py 44 3 93% Missing 30, 54, 67

Este es mi archivo de tests para PricingService ..., ayudame a identificar tests necesarios para cubrir

**Evaluación de la respuesta:** Muy buena, buena,
**Justificación:** me ayudo a comprender la base de la a ctividad para poder abordar las respuestas esperadas del curso, ademas me permitió identificar correctamente las ramas de código que no estaban siendo ejecutadas en los tests
**¿Requirió trabajo adicional?:** sí
**Trabajo adicional realizado:** realizar y revisar manualmente el codigo de checkoutservice y pricingservice para verificar que los casos sugeridos efectivamente correspondieran a las ramas faltantes
## Reflexión final sobre el uso de IA
fue muy útil para identificar rápidamente qué casos de prueba faltaban para aumentar la cobertura del código. También ayudó a comprender mejor cómo funcionan las métricas de code coverage y cómo diseñar tests que cubran diferentes ramas del programa.
